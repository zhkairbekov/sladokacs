# ୨୧ SLADOKACS (Куся) — Сайт-визитка и хаб ссылок

Официальная страница-визитка для Twitch-стримерши **[sladokacs](https://www.twitch.tv/sladokacs)**

🌐 **Сайт:** [https://sladokacs.netlify.app/](https://sladokacs.netlify.app/)

---

## 📁 Структура проекта

Проект написан на чистом **HTML5, CSS3 и Vanilla JavaScript** без внешних сборщиков и тяжёлых библиотек — работает мгновенно и открывается в любом браузере.

```text
sladoka-kusya/
├── index.html        # Разметка страницы, SEO мета-теги, Schema.org (JSON-LD), ссылки и разделы
├── styles.css        # Стили, анимации, фирменные цвета и мобильный таб-бар
├── script.js         # Логика фильтров, автоперевод часового пояса, FAQ-аккордеон и скролл-спай
├── favicon.svg       # Фирменная иконка вкладки браузера (розовый бантик ୨୧ со звездочкой)
├── site.webmanifest  # PWA-манифест для мобильных браузеров
├── robots.txt        # Правила индексации для поисковых роботов Google и Яндекс
├── sitemap.xml       # Карта сайта для поисковых систем
└── README.md         # Документация проекта
```
